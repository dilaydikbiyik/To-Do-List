# To-Do List

A minimal, dependency-free to-do list app built with vanilla HTML, CSS, and JavaScript. Add tasks, mark them done with a click, and remove them with a double-click.

## Features

- Add new tasks via a text input
- Click a task to mark it as completed (strikethrough)
- Double-click a task to remove it
- Clear button to reset the list
- No frameworks, no build step — just open the HTML file

## Tech Stack

HTML5, CSS3, vanilla JavaScript (DOM APIs only, no dependencies).

## Project Structure

```text
To-Do-List/
├── index.html   # Markup
├── style.css    # Styling
└── script.js    # App logic (add / complete / remove tasks)
```

## Getting Started

No installation required. Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/dilaydikbiyik/To-Do-List.git
cd To-Do-List
open index.html   # or double-click the file / use a Live Server extension
```
